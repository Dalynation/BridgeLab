# BridgeLab 0.9.1 preview

Download **BridgeLab-0.9.1-mac-preview.zip** from this release, extract it, and move BridgeLab.app to Applications or Desktop. GitHub's Source code ZIP is not the app download.

Open BridgeLab, import your extracted Windows VST2 instrument DLL or its folder, then scan for plugins in FL Studio. Each import appears as its own BridgeLab instrument in the Channel Rack. Original DLLs are not included.

Tested: SQ8L x86 and TAL-NoiseMaker x64, usable original editors, audio, multiple independent instances, and exact SQ8L FL project audio recall after clean reinstall. Host: Apple Silicon, macOS 15.6.1, FL Studio 24.2.2.4259.

Experimental and ad-hoc signed, not notarized. Other Macs, macOS/FL versions and plugins remain unverified. Apple Silicon requires Rosetta. Windows VST3 and audio-input effects are outside current support. See README for remaining MIDI/automation and editor limitations.
